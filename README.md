# G-NET97 Advanced C# — Assignment 3: Generic Collections

C# console application practicing .NET generic collections across 6 exercises.

## Exercises

1. **Student Grade Manager** — `List<int>` (sort, `Find`, `FindAll`, `RemoveAll`, `ConvertAll`)
2. **Leaderboard** — `SortedDictionary<int, string>`
3. **Phone Book** — `Dictionary<string, string>` (`Add`/`TryAdd`/`GetValueOrDefault`, exception handling)
4. **Unique Email Validator** — `HashSet<string>` with case-insensitive comparer
5. **Exercise 5** — Collections practice
6. **Exercise 6** — Collections practice

`Helpers/ConsoleHelper.cs` provides shared console print-formatting utilities.

## How to Run

```bash
dotnet run
```
